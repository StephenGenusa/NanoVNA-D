# Cut and trim
- Cut 2-3% long. Deploy at the final geometry.
- Ground system first, then tune. Tune first = tune twice.
- Fold the tail back PARALLEL, 1-2 cm clear, secured.
- Do not twist it around the wire. Never coil it:
  a coil is an inductor and the tuning walks.
- Tuned in the folded configuration only.
- Retune if the ground system or the height moves.
## Per folded inch
| Band | shift per inch |
|---|--:|
| 80 m | about 4.8 kHz |
| 40 m | about 17 kHz |
| 20 m | about 70 kHz |

## With the NanoVNA
- MARKER -> SEARCH -> MINIMUM on an SWR trace, or
  MEASURE -> RESONANCE for the exact X = 0 point
- Write down the whip length per band: next time is a
  recall, not a tune
