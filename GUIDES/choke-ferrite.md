# Ferrite mixes
| Mix | Class | Use |
|---|---|---|
| 31 | MnZn | HF chokes 160-20 m; suppression 1-500 MHz |
| 43 | NiZn | chokes 40-10 m, usable 6/2 m |
| 44 | NiZn | modern 43 replacement, higher resistivity |
| 52 | NiZn | 30 m-6 m; flatter broadband |
| 61 | NiZn | above 200 MHz; transformers, not HF chokes |
| 73 | MnZn | LF/MF EMI beads, about 1-25 MHz |
| 75 | MnZn | LF EMI snap-ons, below about 30 MHz |

- MnZn mixes (31, 73, 75) are high permeability and
  lossy low in frequency; NiZn (43, 52, 61) work from
  a few MHz to several hundred MHz
- #31 exhibits both resonances of the choke model, so
  one #31 choke covers about an octave more than #43,
  and holds up better with temperature on low HF
- Lossy is a feature in a choke: you want R, not X
- Verify a bead or core with the analyser: mixes drift
  and unmarked cores are common

Source: K9YC RFI, Ferrites and Common Mode Chokes;
Fair-Rite material classes (permeability values omitted:
not verified against current datasheets)
