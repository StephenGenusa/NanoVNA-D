# Status letters
| Letter | Meaning |
|:-:|---|
| C0-C6 | calibration applied, from slot 0-6 |
| C* | calibration applied, not saved |
| c0-c6 | applied but **interpolated** |
| O | OPEN standard collected |
| S | SHORT collected (before DONE) |
| D | directivity Ed (from LOAD) |
| R | reflection tracking Er |
| S | source match Es |
| T | transmission tracking Et (THRU) |
| t | THRU collected (before DONE) |
| X | isolation Ex (ISOLN) |
| E | enhanced response on |
| P2..P8 | source drive 2-8 mA |
| Pa | source drive auto |
| s2..s9 | smoothing on, factor |
