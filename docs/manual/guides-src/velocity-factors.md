# Velocity factors
| Cable | VF | Dielectric |
|---|--:|---|
| RG-58, RG-213, RG-8 (solid PE) | 0.66 | polyethylene |
| RG-8X, LMR-240 (foam) | 0.82 | foam PE |
| LMR-400 | 0.85 | foam PE |
| RG-174, RG-316 | 0.69 | PE / PTFE |
| 300 ohm twin lead | 0.82 | PE |
| 450 ohm window line | 0.91 | PE, windowed |
| Open-wire line | 0.95 | air |

Set it in DISPLAY -> TRANSFORM -> VELOCITY FACTOR
before a cable length (TDR) measurement.
